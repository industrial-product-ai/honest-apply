# Changelog

All notable changes to HonestApply are documented in this file.

## [0.2.1] - 2026-08-26

### Added

- MIT License for public Skill installation, use, modification, and distribution

## [0.2.0] - 2026-08-26

### Added

- Installable Codex Skill instructions and UI metadata
- Natural-language-first workflow with attachment prompt-injection boundaries
- Explicit privacy, truthfulness, and per-application approval safeguards
- Standard-library JSON entrypoint for deterministic agent use
- JSON entrypoint integration test
- Skill installation and invocation guidance

## [0.1.0] - 2026-08-26

### Added

- YAML-based candidate, job, and preference inputs
- Experience, English level, verified-claim, work-mode, and role checks
- Restricted-claim and conflicting-claim protection
- Readable input validation errors
- Custom command-line input paths
- Seven automated tests
- GitHub Actions test workflow

### Known limitations

- No resume generation or document export
- No job-page extraction
- No browser automation or application submission
- Exact text matching is used for verified claims
